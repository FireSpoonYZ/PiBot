# Google account connection

1. Call `google_setup` with `action="show"` first. Read the returned current state, Center readiness, blockers, owner card, and executable instructions. In Code Mode Only, inspect and invoke `google_setup` through codemode's registered `tools.*` / `describeTool` interface. Do not search provider authentication, automation, or capability installation tools for this request.
2. If `show` reports a running wizard is ready to finish, call `google_setup` with `action="done"` to finalize its card without another owner action. If the requested account/services are ready, report that verified state and proceed with the user's authorized task. Do not restart setup or reconfigure the Center client.
3. If a wizard is running, continue its existing card and current step. If no wizard is active and the requested connection is not ready, call `google_setup` with `action="start"`, then follow its returned card. When the wizard asks for the OAuth audience, end the turn and let the owner answer on that card. Do not use `ask_user_question` for the wizard’s choices. If Center requires an administrator, explain the actual blocker instead of attempting to grant yourself access.
4. Use the returned instructions for non-sensitive setup work. In the built-in browser, let the user take over to sign in to Google Cloud or review terms. Use the system browser when the owner card opens the Center Google API consent flow or the device cannot show the page privately. In Do it for me, the supported desktop client creates and imports the Web OAuth client in its private window without a second confirmation. If that is unavailable, the user enters Client Secrets only through the private owner card. Keep passwords, Client Secrets, OAuth tokens, and callback URLs out of chat and tool calls. Use `action="need_user"` for the handoff and end the turn when only user action remains.
5. After the user returns, call `action="show"` again. Use `action="done"` when the current workflow calls for it. Report completion only after Center verifies that the selected services are ready.
